# Integrated PawnIO installation — French

Goal: retain DevicePulse 0.9.9 UI/DDR features and administrator manifest, embed the exact official PawnIO.Setup 2.2.0 installer, and offer its installation from a French consent dialog on supported computers where no driver is installed.

Runtime: user confirms Installer or chooses Plus tard. Setup uses official -install -silent switches. SHA256 and Authenticode publisher verified before execution; payload is extracted under Program Files and held read-only against replacement. Installed/rejected versions are not overwritten. Exit 3010 requests a Windows restart without automatically restarting. Failure or cancellation never prevents the application from opening. Success is followed by installed-driver verification and sensor activation.

Verification: Windows regression RED on old app; tests for consent policy, all diagnostic bypasses, preserving existing drivers, embedded hash, exit code classification and French layout. Existing self-tests and UI regression suite remain required. CI verifies installer SHA256/signature but MUST NOT execute setup, install a driver or launch the final elevated EXE.

Deliverable: version 0.9.10 self-contained Windows x64 EXE plus verified SMART DLL/notices in ZIP; French setup instructions and manifest proof.
