DevicePulse 0.9.16 — Windows 10/11 x64

FRANÇAIS
Décompressez entièrement cette archive puis lancez DevicePulse.exe.
Conservez libcdi.dll et le dossier smartmontools à côté du programme.
Windows demande les droits administrateur. Si nécessaire, le programme
propose en français l’installation du pilote officiel signé PawnIO 2.2.0.

РУССКИЙ
Распакуйте весь архив и запустите DevicePulse.exe.
Оставьте libcdi.dll и папку smartmontools рядом с программой.
Windows запросит права администратора. При необходимости программа
предложит установку официального подписанного PawnIO 2.2.0 на французском.

ENGLISH
Extract the entire archive and run DevicePulse.exe.
Keep libcdi.dll and the smartmontools folder beside the application.
Windows requests administrator rights. When needed, the application offers
to install the official signed PawnIO 2.2.0 driver in French.
